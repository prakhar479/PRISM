# tables/ schema

Every table is generated by `scripts/make_tables.py` from ingested runs (`runs/`), never edited by hand. Smoke and
tiny-model runs are excluded. Each row traces to a run via `run_hash` (and `RESULTS_INDEX.md` -> release tag).

## Summary tables (E0_pilot_regression, E1_rescored, E2_baselines, E6_layers, E7_estimators)

One row per (run, cell, filter, condition key).

| column | meaning |
|---|---|
| run_hash, config_name, commit | provenance |
| task, layer, sae | cell; `sae` = `L<layer>_<width>_l0<variant>` (Gemma Scope `average_l0_<variant>`) |
| role | confirmatory / exploratory (from the config; PREREGISTRATION.md) |
| filter | pair subset: f_none, f_A_correct, f_both_correct, f_pilot (harness/tasks.py) |
| condition | harness/conditions CONDITIONS; `clean_B` is the unpatched B run through the patch path |
| estimator, source, r, seed | direction (empty / -1 if none); source same_task, other_task:<task>, generic, layer:<L>, random |
| n_pairs | test pairs in this subset with a valid row (resampled-error rows without a donor are excluded) |
| nldr, nldr_pair_mean | (mean D_p - mean D_B)/(mean D_A - mean D_B) (pilot convention) and the mean of per-pair ratios |
| prob_recovery(_pair_mean) | same with p_A (softmax over the full vocabulary, post-softcap logits) |
| D_mean, logprob_diff_mean | mean logit(ans_A) - logit(ans_B) |
| p_A, p_B, p_other_candidates, p_rest | mean probabilities: A's answer, B's answer, other candidate answers, everything else |
| cand_entropy | mean entropy (nats) of the distribution renormalised over candidate answers |
| top1_is_A / top1_is_B / top1_other | three-way top-1 outcome shares |
| flip_rate, flip_n_eligible | mean top1 == A's answer over pairs whose clean B run has top1 == B's answer; their count |
| <metric>_lo, <metric>_hi | 95% paired percentile bootstrap (10 000 resamples over pairs, seed = config seed) |
| gap_<metric> | M(full_A) - M(condition) within the same cell and filter |
| share_closed_<metric> | repair: (M - M(feat_A_errB)) / gap(feat_A_errB); repair_mean: against feat_A_meanPos |

## E0_regression.csv

| column | meaning |
|---|---|
| task, layer, condition, estimator, r | harness condition on the f_pilot subset |
| nldr, nldr_lo, nldr_hi | harness value (seed-averaged for noise and random directions, as the pilot reported) |
| pilot_nldr, pilot_lo, pilot_hi | pilot value from results/paper_20261026_001341/paper_residue/metrics |
| abs_diff_points, within_1_point | acceptance criterion of E0 (handoff: +-1 NLDR point) |

## <exp>_<name>_random.csv

Per (cell, filter, condition, r): distribution of `metric` over random-direction seeds: n, mean, p95, max.
